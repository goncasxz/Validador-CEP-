# Validador de CEP - TDD e Gitflow

Este projeto contém uma função para validação de CEP de acordo com a cidade, desenvolvido com a metodologia TDD e versionado com Gitflow.

## Exemplos de Validação

* CEP: 18.050-100 - Sorocaba (ok)
* CEP: 18.195-000 - Capela do Alto (ok)
* CEP: 18.130-020 – São Roque (ok)
* CEP: 19.000-000 - Votorantim (ERRO)
